| T-02-16 | Spoofing | RecipeDetailView missing-ingredient rendering | high | mitigate | Renders `recipe.missingCategoryNames` exactly as returned by the server — no client-side derivation, recomputation, or caching of a separately-fetched category list that could drift from the server's own answer |
| T-02-17 | Tampering | RecipeForm submission of stale `id` on edit | low | accept | `recipe.id` is read from the already-fetched, server-sourced `Recipe` object passed into the form; no client-writable id field exists in `recipeInput`/`recipePatch`, so a submitted edit can only ever target the id the UI already displayed |
