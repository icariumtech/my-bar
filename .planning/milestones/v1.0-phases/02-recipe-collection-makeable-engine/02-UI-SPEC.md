## Color

Inherited from Phase 1 (60/30/10 color split):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#18181b` (zinc-900) | Page background, recipe list background |
| Secondary (30%) | `#27272a` (zinc-800) | Recipe rows, form surfaces, glassware list items |
| Accent (10%) | `#22c55e` (green) | Makeable status badge, primary CTA buttons ("Add Recipe", "Save Recipe"), active recipe filter, glassware/category filters in recipe form |
| Destructive | `#ef4444` (red) | Not-makeable status badge, delete-recipe/delete-glassware confirmations, "missing ingredient" visual emphasis |

### Accent Reserved For (Phase 2 Additions)

Accent (`#22c55e`) is reserved **exclusively** for:
- **Makeable status badge** on recipe rows and detail (✓ Can make this drink)
- **Primary CTA buttons** ("Add Recipe", "Save Recipe", "Add Method Step", "Add Glassware", when in create mode)
- **Active/selected state** of recipe filters (category filter in recipe form, if implemented)
- **Active tab indicator** for "Recipes" tab in Barback navigation

Never used for body text, non-primary buttons, form hints, or decorative elements. The not-makeable badge uses the destructive color (#ef4444).

### Focal Points (Phase 2)

The **RecipeList** (vertical scrolling list of recipe rows showing name + makeable badge) is the primary visual anchor. The **"Add Recipe" CTA** is held in a persistent header/sticky position using the accent color to draw attention. For not-makeable recipes, the **missing ingredients note** (Destructive-colored or prominent text) is a secondary focal point, surfaced on detail view and inline in some recipe rows.

## Component Inventory (Phase 2 Additions to Phase 1)

Phase 2 adds the following antd-based components and patterns to the existing Barback app:

### Recipe Management
- **RecipeList**: Vertical list of recipe rows, each showing name + makeable status badge + edit/delete affordances
- **RecipeRow**: Single recipe item (secondary-surface card, `#27272a` background) with inline makeable indicator
- **RecipeDetailView**: Full recipe display (name, ingredients with quantities, method steps, glassware, garnish, makeable status + missing ingredients)
- **RecipeForm**: Create/edit recipe form with:
  - Name input (text field, required, max 200)
  - IngredientList (sub-component): add/edit/delete ingredient lines, each with quantity input, unit dropdown, category selector
  - MethodStepList (sub-component): numbered steps, add/edit/delete step text lines
  - GlasswareSelector: dropdown (or linked list picker) for selecting glassware, or "None"
  - GarnishInput: free-text field for garnish description
  - Submit button ("Save Recipe", `#22c55e` accent, 48px min height)
  - Cancel/Back navigation

### Glassware Management
- **GlasswareManager**: Curated list UI, mirrors Phase 1's CategoryManager pattern
  - GlasswareList: Vertical list of glassware entries with edit/delete affordances
  - GlasswareAddEditForm: Inline/modal form for add/rename glassware (single text field, required, max 200)
  - DeleteGuard: Blocks deletion if glassware is referenced by any recipe; shows usage count

### Supporting UI Elements
- **MakeableStatusBadge**: Small badge or pill showing "Ready to make" (accent `#22c55e`) or "Missing ingredients" (destructive `#ef4444`)
- **MissingIngredientsNote**: Prominent text/alert on recipe detail showing "Missing: [comma-separated category names]" in destructive color or bold
- **UnitDropdown**: Fixed options: oz, dash, splash, barspoon, muddled, part — no free text
