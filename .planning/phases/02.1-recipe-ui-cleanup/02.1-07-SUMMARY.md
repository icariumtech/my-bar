# Phase 2.1 Plan 07: Recipe Detail Full-Screen View + Per-Line Tri-State Summary

**Converted RecipeDetailView from a Modal to a full-screen view (D-26) and added the per-line tri-state status dots and yellow-state hint copy that plan 02.1-01 deliberately deferred — closing out both MATCH-05's remaining UI surface and BARBACK-02 as the phase's final plan.**

## Performance

- **Duration:** ~12 min
- **Completed:** 2026-08-12
- **Tasks:** 2

## Accomplishments

- `views/RecipeDetailView.tsx` — full-screen replacement for the old Modal, using the identical header+back-button shell established by `AddEditIngredientView`/`AddEditRecipeView`; keeps the recipe-level `MakeableStatusBadge` and the exact red "Can't make this right now. Missing: [...]." sentence from plan 02.1-01 unchanged
- Adds one yellow-hint paragraph per 'yellow' ingredient line naming both the selected (out-of-stock) ingredient and its in-stock alternative, per the UI-SPEC Copywriting Contract
- Adds a small colored dot (green/yellow/red) before every ingredient line's text, giving line-level tri-state visibility that was previously collapsed into the single recipe-level badge
- `RecipesTab` now imports and renders the full-screen detail view (no Modal, no list rendered underneath) via the same conditional-full-screen-render pattern already used for add/edit
- Old Modal-wrapped `apps/barback/src/components/RecipeDetailView.tsx` deleted — fully superseded
- `BARBACK-02` marked complete in REQUIREMENTS.md — every add/edit/detail flow across Ingredients, Categories, Glassware, and Recipes (add/edit/detail) is now a full-screen view with a back action; no modal-on-modal navigation remains anywhere in Barback
