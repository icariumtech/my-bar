<objective>
Add a parallel "+ Add new category "X"" option to IngredientPicker.tsx's own "Add New" options group, alongside the existing "+ Add new ingredient "X"" option, so the owner can create a bare category (e.g. "Whiskey") directly from the recipe ingredient-line search without being forced through the specific-ingredient creation sub-flow.

Purpose: Today, typing a category name that doesn't exist yet only offers "+ Add new ingredient", which opens the inline-ingredient sub-form (a specific-bottle creation flow requiring a category to already exist) — there is no way to create a bare category from this picker at all, even though "any Whiskey" with no specific bottle required is a completely valid recipe line.
Output: IngredientPicker.tsx offers "+ Add new category "X"" whenever no existing category exactly matches (case-insensitive), and selecting it immediately creates and selects the category via useCreateCategory — the exact same immediate create+select behavior CategoryPicker.tsx's own inline "+ Add" already uses, applied here as a sibling code path to (not a replacement for) the existing ingredient-creation sub-flow.
</objective>
